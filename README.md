# VFP9_MYSQL

Proyecto Visual FoxPro 9 con integracion MySQL.

## Versionado

Este repositorio versiona fuentes VFP, formularios/reportes y salidas FoxBin2Prg (`.sc2`, `.fr2`, `.vc2`, `.mn2`, `.pj2`).

Los compilados, runtimes, logs, backups, indices y configuraciones locales quedan fuera por `.gitignore`.
